## How It Works

1. **Sketch**: Draw freely on the 2D canvas
2. **Export**: Save your drawing as an image for use anywhere

## Quick Start

### Prerequisites

- Node.js 18+

### Setup

```bash
cd frontend
npm install
npm run dev
```

## Architecture

### Frontend

- **Next.js & React**: Responsive, user-friendly UI
- **TLDraw**: Powerful 2D drawing canvas

## Inspiration

Creativity is often constrained by technical skills or complex software. Vibe Draw makes digital sketching accessible to anyone regardless of artistic or technical abilities.

Our goal is to empower people to freely express their imagination and bring their ideas effortlessly into images.
